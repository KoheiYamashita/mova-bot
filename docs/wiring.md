# MOVA 配線ガイド

配線はステップ1から順番に進めてください。各ステップが完了してから次へ進むこと。

使用部品: Core S3、PCA9685、TB6612FNG x2、DCモーター x4、外部バッテリー (7.4V〜12V)

---

## ステップ 1: Core S3 + バッテリー → PCA9685

PCA9685 には接続箇所が2つある。

**左側ピンヘッダー** に Core S3 を接続 (4本):

| Core S3 Port A | PCA9685 ピンヘッダー | 用途 |
|----------------|---------------------|------|
| GPIO2 (SDA) | SDA | I2C データ |
| GPIO1 (SCL) | SCL | I2C クロック |
| 5V | VCC | ロジック電源 (5V) |
| GND | GND | グランド |

**上部の緑スクリュー端子** (POWER と印字) にバッテリーを接続 (2本):

```
  緑スクリュー端子 (上から見た図、ピンヘッダーが左側の向き)
  ┌─────┬─────┐
  │ V+  │ GND │
  │(左) │(右) │
  └─────┴─────┘
   ↑        ↑
  BAT+    BAT−
```

| 接続元 | PCA9685 緑端子 | 用途 |
|--------|---------------|------|
| バッテリー (+) | V+ (左) | モーター駆動電源 (7.4V〜12V) |
| バッテリー (−) | GND (右) | グランド |

> ピンヘッダーの GND と緑端子の GND は基板内部で繋がっている。これにより Core S3 とバッテリーの GND が自動的に共通になる。
>
> **確認方法:** テスターの導通モードで、左側ピンヘッダーの GND と緑端子の右側が導通すれば正しい。

---

## ステップ 2: PCA9685 → TB6612FNG (電源)

PCA9685 から TB6612FNG に電源 3種 (VCC, VM, GND) を供給する。

```
PCA9685                          TB6612FNG #1      TB6612FNG #2
右側ピンヘッダー VCC ──────────→ VCC ─────────────→ VCC
下部チャンネルピン V+ (任意の列) ──→ VM
下部チャンネルピン V+ (別の列) ───────────────────→ VM
下部チャンネルピン GND (任意の列) ─→ GND
下部チャンネルピン GND (別の列) ──────────────────→ GND
```

各線の詳細:

| # | PCA9685 の取り出し場所 | 接続先 | 用途 |
|---|----------------------|-------|------|
| 1 | 右側ピンヘッダー VCC | TB6612FNG #1 VCC | ロジック電源 (5V) |
| 2 | TB6612FNG #1 VCC から分岐 | TB6612FNG #2 VCC | ロジック電源 (5V) 数珠つなぎ |
| 3 | 下部チャンネルピン V+ (任意の列) | TB6612FNG #1 VM | モーター電源 (バッテリー電圧) |
| 4 | 下部チャンネルピン V+ (任意の列) | TB6612FNG #2 VM | モーター電源 (バッテリー電圧) |
| 5 | 下部チャンネルピン GND (任意の列) | TB6612FNG #1 GND | グランド |
| 6 | 下部チャンネルピン GND (任意の列) | TB6612FNG #2 GND | グランド |

> **注意:** 下部チャンネルピンの V+ はバッテリー電圧 (7.4V〜12V) がそのまま出ている。TB6612FNG の VM (最大15V) には使えるが、VCC (最大5.5V) に繋ぐと壊れる。

> **重要:** GND を繋がないと TB6612FNG が PCA9685 からの信号を正しく認識できない。

> USB-C 給電中は Core S3 は動作するが、モーターは外部バッテリー必須。

---

## ステップ 3: PCA9685 → TB6612FNG #1 (制御信号)

PCA9685 のチャンネル出力を TB6612FNG #1 の制御ピンに接続する (7本)。

| PCA9685 CH | TB6612FNG #1 | 機能 |
|------------|-------------|------|
| CH0 | AIN1 | Motor 0 方向 |
| CH1 | AIN2 | Motor 0 方向 |
| CH2 | PWMA | Motor 0 速度 |
| CH3 | BIN1 | Motor 1 方向 |
| CH4 | BIN2 | Motor 1 方向 |
| CH5 | PWMB | Motor 1 速度 |
| CH12 | STBY | スタンバイ制御 |

---

## ステップ 4: PCA9685 → TB6612FNG #2 (制御信号)

TB6612FNG #2 も同様に 7本接続する。

| PCA9685 CH | TB6612FNG #2 | 機能 |
|------------|-------------|------|
| CH6 | AIN1 | Motor 2 方向 |
| CH7 | AIN2 | Motor 2 方向 |
| CH8 | PWMA | Motor 2 速度 |
| CH9 | BIN1 | Motor 3 方向 |
| CH10 | BIN2 | Motor 3 方向 |
| CH11 | PWMB | Motor 3 速度 |
| CH13 | STBY | スタンバイ制御 |

---

## ステップ 5: TB6612FNG → モーター

TB6612FNG のモーター出力をモーターに接続する。

| TB6612FNG | 端子 | モーター |
|-----------|------|---------|
| #1 A01 / A02 | 2線 | Motor 0 |
| #1 B01 / B02 | 2線 | Motor 1 |
| #2 A01 / A02 | 2線 | Motor 2 |
| #2 B01 / B02 | 2線 | Motor 3 |

> DC モーターに極性はない。CW コマンドで逆回転する場合は A01/A02 (または B01/B02) の2線を入れ替えれば正逆が反転する。

---

## 配線チェックリスト

全ステップ完了後、以下を確認:

- [ ] **ステップ1:** Core S3 + バッテリー → PCA9685 (SDA/SCL/5V/GND/V+/GND) — 6本
- [ ] **ステップ2:** PCA9685 → TB6612FNG #1, #2 (VCC/VM/GND 各3本) — 6本
- [ ] **ステップ3:** PCA9685 CH0〜CH5, CH12 → TB6612FNG #1 — 7本
- [ ] **ステップ4:** PCA9685 CH6〜CH11, CH13 → TB6612FNG #2 — 7本
- [ ] **ステップ5:** TB6612FNG → モーター 4台 — 8本

合計: 約 **34本**

## リファレンス

### TB6612FNG ピン配置

```
          TB6612FNG
  ┌─────────────────────┐
  │ VM  VCC GND STBY    │ ← 電源側
  │                     │
  │ A01 A02  B01 B02    │ ← モーター出力
  │                     │
  │ PWMA AIN1 AIN2      │ ← A側制御入力 (← PCA9685)
  │ PWMB BIN1 BIN2      │ ← B側制御入力 (← PCA9685)
  │                     │
  │ GND GND             │
  └─────────────────────┘
```

### モーター制御の真理値表

| AIN1/BIN1 | AIN2/BIN2 | PWMA/PWMB | モーター動作 |
|-----------|-----------|-----------|-------------|
| HIGH | LOW | PWM | 正転 (CW) — 速度は PWM duty で制御 |
| LOW | HIGH | PWM | 逆転 (CCW) |
| HIGH | HIGH | — | ブレーキ (短絡制動) |
| LOW | LOW | — | 停止 (フリー) |

### 電源系統図

```
Core S3                PCA9685                TB6612FNG #1    TB6612FNG #2
Port A 5V ──────────→ VCC ──────┬──────────→ VCC             VCC ←──┘
Port A GND ─────┬──→ GND ──┬───┼──────────→ GND             GND ←──┘
                │          │   └──────────→ (TB6612FNG #2にも同様に分岐)
                │          │
バッテリー(+) ──┼────→ V+ ──┼──┬──────────→ VM              VM ←──┘
バッテリー(−) ──┘            └──┘
          (PCA9685 GND経由で合流)
```

ポイント: PCA9685 が電源の中継点になる。バッテリーの (−) は PCA9685 GND に繋ぐだけで、Core S3 GND と自動的に共通になる。

### STBY ピンの注意事項

- PCA9685 の出力は起動直後レベルが不定
- モーターが意図せず動作するのを防ぐため、STBY ピンに外付けプルダウン抵抗 (10kΩ) の追加を推奨
- ファームウェアは初期化時に STBY を LOW に設定してからモーター制御を開始する

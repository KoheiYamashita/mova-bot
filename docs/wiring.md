# MOVA 配線ガイド

配線はステップ1から順番に進めてください。各ステップが完了してから次へ進むこと。

使用部品: Core S3、M138 (4ch Encoder Motor Module)、PaHUB2、VL53L0X x4、DCモーター x4、PD対応モバイルバッテリー

---

## ステップ 1: M138 を Core S3 にスタック + 電源接続

M138 は M5-Bus コネクタで Core S3 の底面に直接スタックする。I2C (Wire1: GPIO11/12) は M5-Bus 経由で自動接続される。

**電源**: PD対応モバイルバッテリーから PD 12V ケーブルで M138 の DC5521 ジャックに接続する。

```
PD対応モバブ ──[PD 12V ケーブル]──→ M138 DC5521
                                       │
                                  ┌────┴────┐
                                  │  M138   │ (M5-Bus: Wire1, 0x24)
                                  ├─────────┤
                                  │ Core S3 │
                                  └─────────┘
```

> M138 は Core S3 への電源供給も行う（M5-Bus 経由）。別途 USB-C 給電は不要。

---

## ステップ 2: モーター x4 を M138 に接続

M138 の4つのモーター端子にそれぞれモーターを接続する。

| M138 端子 | モーター | 配置 |
|-----------|---------|------|
| Motor 0 | Motor 0 | FL (前左) |
| Motor 1 | Motor 1 | FR (前右) |
| Motor 2 | Motor 2 | RL (後左) |
| Motor 3 | Motor 3 | RR (後右) |

> DC モーターに極性はない。CW コマンドで逆回転する場合は2線を入れ替えれば正逆が反転する。

---

## ステップ 3: PaHUB2 を Port A に接続

PaHUB2 を Core S3 の Port A に Grove ケーブルで接続する。

| Core S3 Port A | PaHUB2 | 用途 |
|----------------|--------|------|
| GPIO2 (SDA) | SDA | I2C データ |
| GPIO1 (SCL) | SCL | I2C クロック |
| 5V | VCC | 電源 |
| GND | GND | グランド |

---

## ステップ 4: VL53L0X x4 を PaHUB2 に接続

4つの VL53L0X ToF センサーを PaHUB2 の各チャンネルに Grove ケーブルで接続する。

| PaHUB2 CH | センサー | 方向 |
|-----------|---------|------|
| CH0 | VL53L0X #0 | 前方 (FRONT) |
| CH1 | VL53L0X #1 | 右方 (RIGHT) |
| CH2 | VL53L0X #2 | 後方 (REAR) |
| CH3 | VL53L0X #3 | 左方 (LEFT) |

> 全センサーの I2C アドレスは 0x29 (デフォルト)。PaHUB2 がチャンネルを切り替えるため、アドレス変更は不要。

---

## 配線チェックリスト

全ステップ完了後、以下を確認:

- [ ] **ステップ1:** M138 が Core S3 にスタックされている。PD 12V がDC5521に接続されている
- [ ] **ステップ2:** モーター x4 が M138 の各端子に接続されている — 8本
- [ ] **ステップ3:** PaHUB2 が Port A に Grove ケーブルで接続されている — 1本
- [ ] **ステップ4:** VL53L0X x4 が PaHUB2 の CH0-CH3 に接続されている — 4本

合計: Grove ケーブル **5本** + モーター線 **8本** + PD ケーブル **1本**

---

## I2C バス構成

| バス | ピン | デバイス | 用途 |
|------|------|---------|------|
| Wire1 (M5-Bus内部) | GPIO11/12 | M138 (0x24), AXP2101, AW9523 | モーター制御 |
| Wire (Port A) | GPIO1/2 | PaHUB2 (0x70) → VL53L0X x4 (0x29) | 障害物検知 |

```
PD対応モバイルバッテリー
    │
    │ PD 12V
    ▼
M138 DC5521
    │
    ├── モーター x4 駆動電源
    │
    └── M5-Bus → Core S3 給電
```

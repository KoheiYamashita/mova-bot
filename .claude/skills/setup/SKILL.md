# MOVA セットアップウィザード

MOVAロボットのゼロからの構築を対話的にガイドする。各ステップ完了時に進捗を保存し、途中再開が可能。

## 進捗管理

進捗ファイル: `.claude/skills/setup/progress.json`

### 起動時の処理

1. `progress.json` を Read で読み込む (存在しなければ新規作成)
2. 現在のステップを特定する
3. `$ARGUMENTS` にステップ名が指定されていればそのステップへジャンプ
4. 指定なしなら未完了の最初のステップから再開

### progress.json フォーマット

```json
{
  "current_step": "1_overview",
  "completed": ["1_overview", "2_procurement"],
  "started_at": "2025-01-01T00:00:00Z",
  "last_updated": "2025-01-01T01:00:00Z",
  "notes": {
    "2_procurement": "VL53L0X を AliExpress で注文済み、到着待ち"
  }
}
```

### ステップ完了時

ユーザーに完了確認を取り、`progress.json` を更新する。

```
AskUserQuestion: "ステップ X を完了にしますか？"
→ Yes: progress.json 更新 → 次のステップへ
→ No/スキップ: notes にメモを残して次へ (completed には入れない)
```

## ステップ 1: 概要・必要なもの説明 (`1_overview`)

### やること

ユーザーにプロジェクトの全体像と必要な機材一覧を提示する。

### 表示内容

#### MOVAとは

M5Stack Core S3 をベースとした4輪オムニホイールロボット。WiFi 経由で AI エージェントが自律制御する。

主要機能:
- 4方向オムニホイール移動 (前後左右+回転)
- カメラ映像 (GC0308)
- 絵文字ディスプレイ (320x240)
- スピーカー音声再生 + マイク録音
- 4方向 ToF 障害物検知・自動緊急停止

#### ベース車体

市販ラジコンカー ([Amazon: B08K2RQSYV](https://www.amazon.co.jp/dp/B08K2RQSYV)) をベースに使用する。
元のラジコンの上蓋(ボディシェル)と制御基板を取り外し、シャーシ・モーター・ホイールのみを流用する。
上蓋の代わりに 3D プリント製のカバーを被せ、Core S3 やセンサーを搭載する。

> **車体を自作する場合**: 4輪メカナムホイール/オムニホイール + DC モーターのシャーシを自分で設計してもよい。M138 の端子にモーター4つが接続できれば構成は自由。

#### 必要な機材一覧

**A. 電子部品**

| # | 品名 | 数量 | 用途 |
|---|------|------|------|
| 1 | M5Stack Core S3 | 1 | メインコントローラー |
| 2 | 4ch Encoder Motor Module (M138) | 1 | モータードライバー (M5-Bus スタック) |
| 3 | PaHUB2 (TCA9548A) | 1 | I2C マルチプレクサ |
| 4 | VL53L0X ToF センサー (Grove) | 4 | 障害物検知 (前後左右) |
| 5 | PD対応モバイルバッテリー (12V出力) | 1 | 電源 |
| 6 | PD トリガーケーブル (USB-C → DC5521 12V) | 1 | バッテリー → M138 接続 |
| 7 | Grove ケーブル (4pin) | 5 | PaHUB2 + VL53L0X 接続 |
| 8 | microSD カード | 1 | wifi.txt 格納 |

**B. 車体**

| # | 品名 | 数量 | 入手方法 |
|---|------|------|---------|
| 9 | [ラジコンカー (ベース車体)](https://www.amazon.co.jp/dp/B08K2RQSYV) | 1 | シャーシ・モーター・ホイールを流用。上蓋と制御基板は取り外す |
| 10 | 3D プリント製カバー | 1 | `model/` フォルダの STL を 3D プリンターまたは印刷サービス (DMM.make 等) で出力 |

> **3D プリント手段**: 自前の 3D プリンター、もしくは印刷サービスを利用。
> 車体もモーターも含め完全自作する場合は、3D モデルを自分で設計する。

#### 必要なツール・環境

- PC (Linux/macOS/Windows) + USB-C ケーブル
- PlatformIO (VS Code 拡張 or CLI)
- WiFi 環境 (2.4GHz)

### 完了条件

ユーザーが内容を確認し、次のステップに進む意思を示す。

## ステップ 2: 機材の入手 (`2_procurement`)

### やること

機材リストの入手状況を確認し、未入手のものを特定する。

### 処理フロー

1. ステップ 1 の機材リストを表示
2. AskUserQuestion で各機材の入手状況を確認 (まとめて聞く):
   - "以下の機材のうち、まだ入手していないものはありますか？"
   - 選択肢: 主要機材ごとにチェック
3. 未入手品があれば購入先の参考情報を提示
4. 全品揃ったらステップ完了

### 購入先参考

- M5Stack 公式 / Switch Science: Core S3, M138, PaHUB2, VL53L0X, Grove ケーブル
- Amazon: [ベースラジコン (B08K2RQSYV)](https://www.amazon.co.jp/dp/B08K2RQSYV), PD トリガーケーブル (「USB-C PD トリガー DC5521 12V」で検索)
- 3D プリント: 自前プリンター or 印刷サービス (DMM.make 等)。STL は `model/` フォルダを参照

### 完了条件

全機材が手元に揃った。

---

## ステップ 3: 接続 (配線) (`3_wiring`)

### やること

`docs/wiring.md` に従って物理的な配線を行う。

### 処理フロー

1. `docs/wiring.md` を Read して内容を表示
2. ステップごとに進める:
   - ステップ 1: M138 を Core S3 にスタック + 電源
   - ステップ 2: モーター x4 を M138 に接続
   - ステップ 3: PaHUB2 を Port A に接続
   - ステップ 4: VL53L0X x4 を PaHUB2 に接続
3. 各サブステップで AskUserQuestion: "この接続は完了しましたか？"
4. 配線チェックリストを確認

### 完了条件

全配線が完了し、チェックリストを確認済み。

---

## ステップ 4: ビルド & デプロイ (`4_build_deploy`)

### やること

ファームウェアのビルドと書き込み、WiFi 設定。

### 処理フロー

1. **WiFi 設定ファイル作成**
   - AskUserQuestion で SSID と パスワードを確認
   - microSD カードのマウントパスを確認
   - `wifi.txt` を生成して SD カードに書き込み

2. **ファームウェアビルド**
   ```
   pio run -d /home/kohei/workspace/MOVA
   ```
   - ビルドエラーがあれば対処

3. **ファームウェア書き込み**
   - Core S3 を USB-C で PC に接続するよう指示
   ```
   pio run -d /home/kohei/workspace/MOVA --target upload
   ```

4. **LittleFS データアップロード** (Web UI がある場合)
   ```
   pio run -d /home/kohei/workspace/MOVA --target uploadfs
   ```

### 完了条件

ファームウェアの書き込みが成功し、SD カードに wifi.txt を格納済み。

---

## ステップ 5: 組み上げ (`5_assembly`)

### やること

シャーシにコンポーネントを組み付ける。

### 処理フロー

1. **ラジコン分解**
   - ベースラジコンの上蓋 (ボディシェル) を取り外す
   - 元の制御基板・受信機を取り外す (シャーシ・モーター・ホイールはそのまま残す)
2. **3D プリントカバーの準備**
   - `model/` フォルダの STL を確認
   - 3D プリンターまたは印刷サービスで出力
3. **電子部品の組み付け**
   - Core S3 + M138 スタックをシャーシ (または 3D カバー) に固定
   - モーター x4 を M138 端子に接続
   - PaHUB2 を固定し、Port A に Grove ケーブルで接続
   - VL53L0X x4 を前後左右に取り付け、PaHUB2 に接続
   - PD バッテリーを搭載
4. **カバー取り付け**
   - 3D プリントカバーをシャーシに被せて固定
   - ケーブルの取り回しを整理
5. 完成状態の確認を促す

### 完了条件

全コンポーネントがシャーシに組み付けられ、3D カバーが取り付けられ、配線が正しく接続されている。

---

## ステップ 6: 初回起動 & 動作確認 (`6_run`)

### やること

電源投入し、各機能の動作を確認する。

### 処理フロー

1. **電源投入**
   - PD バッテリーを接続し、Core S3 が起動することを確認
   - シリアルモニタで起動ログを確認 (任意):
     ```
     pio device monitor -d /home/kohei/workspace/MOVA
     ```

2. **WiFi 接続確認**
   - ディスプレイに IP アドレスが表示されるか確認
   - AskUserQuestion: "画面に表示された IP アドレスを教えてください"

3. **基本 API テスト** (curl で実行)
   - `GET /status` — レスポンス確認
   - `GET /capture` — カメラ画像取得
   - `POST /command {"emoji":"😀"}` — 絵文字表示

4. **モーターテスト**
   - 各モーター (0-3) を低速で短時間テスト
   - 回転方向が正しいか確認 (逆なら配線入替を指示)

5. **センサーテスト**
   - `/status` の `sensors` フィールドで4方向の距離値を確認
   - 手をかざして値が変化するか確認
   - 障害物検知 → 緊急停止が動作するか確認

6. **mova スキル設定**
   - `.claude/skills/mova/.env` に `MOVA_HOST` を設定
   - `/mova ステータス確認` でスキル経由の動作を確認

### 完了条件

全テスト項目が正常動作。MOVAが操作可能な状態。

## 手順

1. `progress.json` を Read する (なければ初期状態として扱う)
2. 現在のステップを特定する
3. `$ARGUMENTS` があればそのステップへジャンプ、なければ続きから
4. ステップの内容に従って対話的に進める
5. ステップ完了時に AskUserQuestion で確認し、`progress.json` を Write で更新
6. 次のステップへ進むか確認
